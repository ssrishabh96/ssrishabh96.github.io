## About

I'm a Production Engineer at Meta who builds the systems that keep large-scale infrastructure **reliable, scalable, and automated** — the rate-limiting, capacity, and observability machinery that keeps services healthy under enormous load.

My current focus sits where **infrastructure meets AI**: keeping compute-intensive and **model-training workloads** reliable while maximizing how efficiently we use every host and GPU. - **Self-service automation** — automated SLO provisioning, monitoring, and onboarding so platforms scale adoption without scaling operational burden.
